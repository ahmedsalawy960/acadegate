# AcadeGate — ملف عرض للمستثمرين
**بوابتك للتميز في الدراسات العليا**

| البند | التفاصيل |
|------|----------|
| المنتج | منصة أكاديمية ثنائية البوابة (باحث ↔ مقدم خدمة) |
| السوق المستهدف | مصر أولاً — طلاب الدراسات العليا، مشرفون، مختبرات، تجار معدات، كتّاب أكاديميون |
| التقنية | Flutter متعدد المنصات + Firebase (Auth, Firestore, Storage, Cloud Functions) |
| الإصدار | 1.0.0 |
| تاريخ الملف | يوليو 2026 |
| حالة المنتج | جاهز لبيتا مغلقة (تحويل يدوي) — الدفع الإلكتروني (Paymob) مبرمج وجاهز للتفعيل بعد التسجيل القانوني |

> هذا الملف مبني على حالة الكود الفعلية للمنصة، وليس على وعود تسويقية غير منفّذة. أين وُجدت فجوة تشغيلية ذُكرت صراحةً تحت «حالة التنفيذ».

---

## 1) الملخص التنفيذي

### المشكلة
طالب الدراسات العليا في العالم العربي يتنقل بين قنوات متفرقة: مشرف، مختبر، معدات، كتابة، أصالة، مجتمع، ذكاء اصطناعي — غالباً بدون ضمان مالي، وبدون مسار يربط الفكرة بالتنفيذ.

### الحل
**AcadeGate** تجمع الرحلة في تطبيق واحد ببوابتين:

1. **بوابة الباحث/الطالب** — اكتشاف، طلب، دفع، تتبع، أدوات ذكية.
2. **بوابة مقدم الخدمة** — استقبال الطلبات، نشر المحتوى، إدارة العمليات.

### لماذا الآن؟
- المنتج يعمل فعلياً (تجارة + طلبات + أدوات AI + مجتمع).
- نموذج الإيرادات واضح: **عمولة سوق (Marketplace)** على المعاملات + لاحقاً اشتراكات أدوات AI + تراخيص جامعية B2B.
- حاجز الدخول مرتفع نسبياً: تكامل عشرات الخدمات + قواعد أمان + استيراد بيانات (OpenAlex / مختبرات / متجر).

### ما الذي يُطلب من المستثمر؟
تمويل لتسريع: (1) التسجيل القانوني وتفعيل Paymob، (2) تعبئة محتوى حقيقي، (3) إطلاق بيتا جامعية، (4) تسويق أكاديمي، (5) فريق عمليات ودعم.

## 3) نموذج المنصة: طرفان + إدارة

### 3.1 بوابة المستخدم (الباحث / الطالب)
واجهة استهلاك الخدمات: بطاقات رئيسية، بحث، ملف أكاديمي، مطابقة، رسائل، إشعارات داخل التطبيق، تتبع تقدّم الرسالة.

### 3.2 بوابة مقدم الخدمة
واجهة العمليات حسب الدور: تاجر، مسؤول مختبر، مشرف، ناشر أفكار، خبير كتابة. تشمل الطلبات الواردة، النشر، والمتابعة، مع **لوحة المساهمة الكاملة**.

### 3.3 الأدوار

| الدور | الاسم | البوابة المقترحة | ماذا يفعل |
|------|------|------------------|----------|
| student | طالب / باحث | المستخدم | طلبات، شراء، حجز، أدوات |
| supervisor | مشرف أكاديمي | اختيار | ملف، طلبات إشراف، كتابة (اختياري) |
| merchant | تاجر / مورد | مقدم الخدمة | منتجات وطلبات متجر |
| lab_manager | مسؤول مختبر | مقدم الخدمة | مختبر، عينات، حجوزات أجهزة |
| idea_publisher | ناشر أفكار | مقدم الخدمة | نشر أفكار ومتابعة مقترحات |
| admin | مدير | كلاهما | مراجعة، استيراد، تمويل، إعدادات |

المصادقة: بريد/كلمة مرور + Google (+ Facebook/Apple حسب المنصة). التصفح كضيف متاح مع تقييد العمليات الحساسة.

## 4) خريطة الخدمات — شرح دقيق + تصوّر التربح لكل ميزة

لكل قسم أدناه:
- **ماذا يفعل اليوم**
- **كيف يعمل داخل التطبيق**
- **حالة التنفيذ**
- **تصوّر التربح** (آلية + تقدير نوعي + متطلبات التفعيل)

---

### 4.1 المشرفون الأكاديميون

**ماذا يفعل:** دليل مشرفين حسب الكليات، ملف تفصيلي، مقاييس نشر (OpenAlex/Scimago)، مراسلة، طلب إشراف/تواصل.

**كيف يعمل:** كليات → قائمة → ملف → طلب/محادثة. الاستيراد الجماعي عبر OpenAlex أو CSV (إدارة).

**حالة التنفيذ:** جاهز تشغيلياً — يحتاج محتوى حقيقي غزير بدل/إلى جانب أي بيانات تجريبية.

**تصوّر التربح**
| الآلية | الوصف | متى |
|--------|--------|-----|
| عمولة على طلب إشراف مدفوع | نسبة من رسوم الجلسة/الاستشارة عند تفعيل الدفع | بعد Paymob أو تحويل يدوي منظّم |
| اشتراك «ملف مشرف مميز» | إبراز في البحث والمطابقة | بعد قاعدة مستخدمين |
| B2B جامعي | ترخيص عرض مشرفي الجامعة داخل المنصة | شراكات جامعية |
| إعلانات أكاديمية موجهة | ظهور مدفوع لتخصصات | مرحلة نضج |

**هامش مقترح مبدئي:** عمولة 10–15% على الاستشارات المدفوعة؛ اشتراك شهري رمزي للملف المميز.

---

### 4.2 المطابقة الذكية

**ماذا يفعل:** يطابق الملف الأكاديمي (تخصص، اهتمام، منهجية…) مع مشرفين وأفكار ومختبرات ويعطي نقاط توافق.

**كيف يعمل:** يعتمد على اكتمال الملف الأكاديمي؛ تنبيهات عند ظهور مشرف مناسب.

**حالة التنفيذ:** يعمل كمحرك محلي/قواعد — جودة المطابقة ترتفع ببيانات أفضل.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|
| Freemium | عدد محدود من المطابقات مجاناً |
| اشتراك Premium للمطابقة | مطابقات غير محدودة + تنبيهات فورية |
| حزمة «مسار بحث» مدفوعة | دمج المطابقة مع مسار البحث الذكي |

---

### 4.3 سوق الأفكار البحثية

**ماذا يفعل:** نشر أفكار/مشاكل بحثية، تصويت، تقديم مقترحات، مراجعة قبل الظهور العام.

**كيف يعمل:** سوق → تفاصيل الفكرة → مقترح/تصويت. النشر يمر بمراجعة إدارية عند الحاجة.

**حالة التنفيذ:** جاهز؛ يحتاج أفكاراً حقيقية عالية الجودة للبيتا.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|
| رسوم نشر فكرة مميزة | ظهور أعلى / مدة أطول |
| عمولة عند تحويل المقترح لتعاقد | إذا ربطت الفكرة بكتابة/إشراف/مختبر مدفوع |
| رعاية مؤسسات | جامعات/مراكز تنشر تحديات بحثية مدفوعة |

---

### 4.4 مسار البحث الذكي

**ماذا يفعل:** يُدخل الباحث موضوعاً فيحصل على حزمة مقترحة: فكرة ≈ مشرف ≈ مختبر ≈ منتجات متجر ≈ كتابة + تحليل اختياري بالـ AI.

**كيف يعمل:** محرك محلي + إثراء Gemini عند التوفر.

**حالة التنفيذ:** جاهز كميزة تمييزية؛ يعتمد على غنى الكتالوج.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|
| رسوم حزمة Premium | تقرير مسار مفصّل + أولوية مطابقة |
| عمولة إحالة | عند تحويل عناصر الحزمة لطلبات مدفوعة (متجر/كتابة/مختبر) |
| اشتراك شهري «باحث Pro» | يشمل المسار + المطابقة + حصة AI |

**هذه ميزة «قمع تحويل»:** مجانية جزئياً لجذب المستخدم، ومربحة عبر العمولات اللاحقة.

---

### 4.5 مختبرات ومراكز التحليل + تحليل العينات + حجز الأجهزة

**ماذا يفعل:**
- دليل مختبرات وخدمات تحليل.
- طلب تحليل عينة بدورة حالات (قيد المراجعة → تسعير → قبول…).
- حجز أجهزة مع صندوق وارد لمسؤول المختبر.
- مطالبة مختبر غير مربوط / استيراد (إدارة).

**كيف يعمل:** تصفح وفلاتر → تفاصيل → طلب عينة أو حجز جهاز → متابعة من لوحة المساهمة/مقدم الخدمة.

**حالة التنفيذ:** تشغيل طلبات وحجوزات **موجود**. **لا يوجد دفع بطاقة على العينات/الحجوزات بعد** — التسعير والتواصل داخل المنصة (فرصة إيراد لاحقة).

**تصوّر التربح**
| الآلية | الوصف | أولوية |
|--------|--------|--------|
| عمولة على طلب التحليل المدفوع | 8–12% بعد ربط الدفع | عالية |
| عمولة حجز جهاز | نسبة من تكلفة الجلسة | متوسطة–عالية |
| اشتراك مختبر مميز | ظهور أعلى + شارة موثّق | متوسطة |
| رسوم ربط مختبر جامعي B2B | عقد سنوي | عالية لاحقاً |

### 4.6 المتجر الأكاديمي (قناة إيراد أساسية)

**ماذا يفعل:** 5 أقسام (كيميائي، هندسي، طبي، زراعي، عام). إنشاء طلب، اختيار **دفع إلكتروني Paymob** أو **تحويل يدوي**، ضمان Escrow (محجوز → مُفرَج بعد الاستلام)، مراسلة البائع.

**كيف يعمل:** أقسام → منتج → شراء → اختيار طريقة الدفع → إشعار البائع → تأكيد الاستلام/التحويل.

**حالة التنفيذ:**
- التحويل اليدوي: **يعمل الآن**.
- Paymob: **الكود جاهز** (Intention + Webhook + HMAC) ويُفعَّل بعد أسرار + تسجيل قانوني + `ENABLE_PAYMOB`.

**تصوّر التربح**
| الآلية | الوصف | تقدير |
|--------|--------|--------|
| عمولة المنصة على الطلب | 5–12% من قيمة المنتج | أساس الإيراد التجاري |
| رسوم إدراج مورد | اشتراك شهري/سنوي للموردين | إيراد متكرر |
| ترويج منتج مميز | ظهور مدفوع في القسم | هامش إعلاني |
| استيراد كتالوج موردين | خدمة إعداد للموردين الكبار | رسوم مشروع |

**وحدة اقتصادية مبسّطة (مثال):** متوسط سلة 800 ج.م × عمولة 8% = 64 ج.م/طلب. عند 500 طلب/شهر ≈ 32,000 ج.م عمولة قبل التكاليف.

### 4.7 خدمات الكتابة الأكاديمية (قناة إيراد أساسية)

**ماذا يفعل:** 8 تخصصات كتابة بشرية (ليست استبدال AI): أوراق، رسائل، إحصاء، مراجعة أدبيات، مقترحات، تحرير، تنسيق، ترجمة. حجز طلب، قبول/رفض الخبير، دفع (Paymob/يدوي)، تسليم، تأكيد.

**كيف يعمل:** مركز الكتابة → خبراء → حجز → طلباتي / طلبات الخبير الواردة.

**حالة التنفيذ:** دورة الطلب كاملة مع الدفع اليدوي؛ Paymob جاهز بنفس مسار المتجر.

**تصوّر التربح**
| الآلية | الوصف | تقدير |
|--------|--------|--------|
| عمولة على الطلب | 10–20% (أعلى من المتجر لجهد المنصة) | أساس |
| اشتراك خبير مميز | ظهور أعلى + حد أعلى للطلبات | متكرر |
| حزم عاجلة | رسوم إضافية تقسم بين الخبير والمنصة | هامش جيد |
| مطابقة كاتب (Writer Match) | رسوم مطابقة أو ضمن Premium | مكمّل |

### 4.8 المجتمع الأكاديمي وغرف البحث

**ماذا يفعل:** غرف تخصص عامة + غرف بحثية خاصة (كلمة مرور تُدار عبر Cloud Functions) + مناقشات وردود + إشعارات.

**حالة التنفيذ:** جاهز تشغيلياً.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|
| غرف بحث مدفوعة/مؤسسية | جامعة أو مشروع يدفع لإنشاء مساحة خاصة مدارة |
| رعاية محتوى | إعلانات خفيفة غير مزعجة داخل الغرف العامة |
| تحويل للمجتمع → خدمات مدفوعة | الإحالات لكتابة/مختبر (عمولة غير مباشرة) |

المجتمع نفسه ليس أعلى مصدر دخل؛ هو **محرّك احتفاظ وإحالات**.

### 4.9 المساعد الأكاديمي (AcadeGate AI)

**ماذا يفعل:** محادثة متعددة الوكلاء المتخصصين (أفكار، كتابة رسالة، منهجية، مناقشة، مراجع، بيانات…) عبر Gemini (سحابة) مع مرفقات وحفظ محادثات.

**حالة التنفيذ:** يعمل؛ التكلفة الحالية على مفتاح/حصة Gemini — **لا يوجد اشتراك مستخدم مفعّل بعد**.

**تصوّر التربح**
| الآلية | الوصف | ملاحظة |
|--------|--------|--------|
| Freemium | N رسالة/يوم مجاناً | جذب |
| اشتراك باحث Pro | 99–299 ج.م/شهر (حصة أعلى + وكلاء متقدمة) | إيراد متكرر عالي الهامش |
| حزم جامعية | ترخيص لعدد طلاب | B2B |
| Pay-per-use | رصيد رسائل | مرونة |

**اقتصاد الوحدة:** سعر الاشتراك يجب أن يغطي تكلفة Gemini + هامش 50%+ بعد الاستقرار.

### 4.10 محاكي المناقشة (Viva Simulator)

**حالة التنفيذ:** منفّذ كأداة تدريب.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|
| ضمن اشتراك Pro | جلسة واحدة مجانية ثم ضمن الباقة |
| دفع لكل جلسة محاكاة | 30–80 ج.م/جلسة |
| حزمة ما قبل المناقشة | محاكاة + تدقيق منهجية + ملخص نقاط ضعف |

### 4.11 سلامة أكاديمية (مراجع + أصالة) + سلامة المنهجية + تحليل إحصائي

**ماذا يفعل:**
- فحص مراجع (Crossref/OpenAlex/Semantic Scholar).
- فحص تشابه (Copyleaks عبر Cloud Functions).
- تقرير توافق منهجي (تصميم/عينة/تحليل) مع PDF اختياري.
- معالج افتراضات إحصائية محلي (CSV/ملفات).

**حالة التنفيذ:** أدوات عاملة؛ تكاليف Copyleaks/Gemini على المنصة حالياً.

**تصوّر التربح**
| الأداة | التربح |
|--------|--------|
| فحص الأصالة | دفع لكل فحص أو ضمن Pro (مع حد) — يمرّر تكلفة المزوّد + هامش |
| فحص المراجع | ضمن Pro أو رسوم تقرير |
| سلامة المنهجية | تقرير مدفوع / ضمن حزمة المناقشة |
| التحليل الإحصائي | مجاني كجذب أو Pro |

### 4.12 AcadeGate — النشر العلمي

**تصوّر التربح**

| اشتراك ناشر أكاديمي | مخطوطات متعددة + قوالب |
| عمولة إحالة لمجلات/تحرير مدفوع | شراكات لاحقة |

### 4.13 صندوق تمويل البحث

**ماذا يفعل:** واجهة تمويل أفكار عند تجاوز عتبة تصويت؛ إعداد شركاء وجوائز من الإدارة.

**حالة التنفيذ:** **غير مفعّل للمستخدم حتى يضبط المدير الشركاء/الإعدادات** — يظهر كصندوق غير مفعّل.

**تصوّر التربح**
| الآلية | الوصف |
|--------|--------|

| رعاية شريك جامعي/صناعي | رسوم ظهور الشريك كممّول |
| ليس «استثمار جماعي عام» حالياً | نموذج شراكة مضبوط لتجنّب مخاطر تنظيمية مبكرة |

### 4.15 الرسائل والإشعارات والملف الأكاديمي ورحلة الرسالة

**ماذا يفعل:** محادثات 1:1، إشعارات داخل التطبيق (عبر Cloud Function مؤمّنة بعلاقة طرفين)، ملف أكاديمي يغذي المطابقة، تتبع مراحل الرسالة.

**حالة التنفيذ:** جاهز؛ **إشعارات Push (FCM من السيرفر) غير مكتملة** — التوكن يُحفظ لكن الإرسال الجماعي من السيرفر غير مفعّل بعد.

**تصوّر التربح:** بنية تحتية ثقة واحتفاظ — لا تُسعَّر منفصلة؛ تزيد معدل إتمام الطلبات المدفوعة.

---

### 4.16 لوحة المساهمة / الإدارة / الاستيراد

**ماذا يفعل:** مراجعة محتوى، استيراد مشرفين ومختبرات ومتجر، عمليات مختبرات غير مربوطة، إعداد تمويل ومجلات.

**تصوّر التربح:** تمكّن العرض (Supply) بسرعة → يزيد المعاملات → يزيد العمولات. يمكن بيع «خدمة إعداد محتوى» للجامعات والموردين كمشروع استشاري.

## 5) نموذج الإيرادات المجمّع (كيف تربح المنصة ككل)

```
إيرادات AcadeGate ≈
  عمولات المتجر
+ عمولات الكتابة
+ (لاحقاً) عمولات المختبر/العينات/الحجز
+ اشتراكات باحث Pro / مشرف مميز / مختبر مميز
+ تراخيص B2B جامعية
+ رسوم أدوات (أصالة، محاكاة، تنسيق نشر)
+ رعايات وإعلانات أكاديمية محدودة
```

### أولوية توليد النقد (12 شهراً)

| الترتيب | المصدر | لماذا |
|---------|--------|--------|
| 1 | عمولة المتجر + الكتابة | مسارات دفع موجودة (يدوي الآن / Paymob جاهز) |
| 2 | اشتراك AI/Pro | هامش مرتفع بعد ضبط التكلفة |
| 3 | عمولة مختبرات بعد ربط الدفع | طلبات موجودة تحتاج checkout |
| 4 | B2B جامعي | دورة بيع أطول لكن عقد أكبر |
| 5 | رعايات/إعلانات | بعد قاعدة مستخدمين |

### ما ليس مصدر دخل حالياً
- لا اشتراكات مستخدم مفعّلة في الكود بعد.
- لا عمولة تلقائية تُخصم من Paymob — تُصمَّم محاسبياً عند التفعيل (نسبة منصة على المبلغ أو فاتورة شهرية للموردين).

## 10) الخلاصة للمستثمر

AcadeGate ليست «فكرة تطبيق» فقط: هي **منصة تشغيلية ثنائية الجانب** تجمع اكتشاف الموارد الأكاديمية مع مسارات تجارة (متجر/كتابة) قابلة للعمولة، وأدوات ذكاء تُحوَّل لاحقاً لاشتراكات عالية الهامش، مع مسار واضح من بيتا يدوية إلى دفع إلكتروني مؤسسي.

**الطلب:** شريك رأسمالي ي موّل الانتقال من «منتج يعمل» إلى «سوق يعمل بأرقام» عبر المحتوى، الامتثال، والتفعيل التجاري.
