# قائمة اختبار AcadeGate قبل الإطلاق

استخدم هذا الملف أثناء التجربة. ضع ✅ أو ❌ ولاحظ الخطأ في عمود الملاحظات.

**التحضير قبل البدء**
- [ ] اتصال إنترنت مستقر (Firebase يحتاج شبكة)
- [ ] التطبيق يعمل (`flutter run`)
- [ ] حساب باحث (طالب) مسجّل
- [ ] حساب مقدم خدمة ثاني إن أمكن (تاجر أو مسؤول مختبر) — لاختبار الطلبات بين طرفين
- [ ] Hot Restart (`R`) بعد أي نشر Firebase
