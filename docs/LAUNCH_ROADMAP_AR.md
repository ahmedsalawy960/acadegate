# خريطة إطلاق AcadeGate

**الحالة الآن:** جاهز لبيتا مغلقة (تحويل يدوي) — غير جاهز لإطلاق عام + Paymob قبل التسجيل القانوني.

---

## الجواب المختصر

ابدأ بإطلاق محدود (أصدقاء / باحثون موثوقون) بالتحويل اليدوي.  
السجل التجاري والبطاقة الضريبية مطلوبان قبل الدفع الإلكتروني الواسع ونشر المتاجر رسمياً.  
شريك دائم ليس شرطاً في المرحلة الأولى.

| المرحلة | المدة التقريبية | الهدف |
|--------|------------------|--------|
| أ — جاهزية تقنية | 1–2 أسابيع | أمان + اختبار يدوي |
| ب — بيتا مغلقة | 2–4 أسابيع | 10–30 مستخدماً |
| ج — قانوني + متاجر | 1–3 أشهر | سجل / Play / App Store |
| د — Paymob مباشر | بعد التسجيل | دفع إلكتروني |

---

## مرحلة أ — ثبّت الأساس

- [x] نشر قواعد Firestore + Storage + دالة الإشعارات
- [x] تعيين `COPYLEAKS_WEBHOOK_SECRET`
- [ ] اختبار: تسجيل → منتجك → تحويل يدوي → تأكيد البائع
- [ ] إخفاء أو «قريباً» للتمويل / بيانات demo الواضحة
- [ ] مسودة سياسة خصوصية + شروط استخدام (صفحة لكل منهما)

---

## مرحلة ب — بيتا مغلقة (موصى بها أولاً)

- [ ] قائمة 10–30 مدعواً + واتساب/إيميل دعم
- [ ] سجل بسيط للمشاكل (خطأ / ميزة / دفع)
- [ ] التأكد أن البائع يؤكد الاستلام → `paid_held`
- [ ] عدم الاعتماد على بيانات demo في الواجهة العامة
- وزّع APK أو رابط اختبار داخلي فقط — لا إعلان عام بعد

---

## مرحلة ج — قانوني ومتاجر (قبل الإطلاق العام)

| البند | لماذا | متى |
|------|--------|-----|
| سجل تجاري + بطاقة ضريبية | غالباً مطلوب لـ Paymob Live | قبل الدفع الإلكتروني العام |
| حساب بنكي باسم النشاط | استلام التحويلات | مع أو قبل التسجيل |
| سياسة خصوصية + شروط | مطلوبة من المتاجر | قبل الرفع |
| حساب Google Play | نشر Android | عند الإعلان العام |
| حساب Apple Developer | نشر iOS (اختياري) | نفس التوقيت أو لاحقاً |
| حقوق نشر / محتوى أكاديمي | تجنّب مواد مسروقة أو وعود مضللة | من اليوم الأول |

> هذا ليس استشارة قانونية رسمية — راجع محاسباً/محامياً في مصر.

---

## مرحلة د — Paymob

1. حساب Paymob ووضع الاختبار أولاً  
2. بعد الموافقة: مفاتيح live + أسرار Firebase + تفعيل `ENABLE_PAYMOB`  
3. اختبار بمبلغ صغير  
4. الإبقاء على التحويل اليدوي كاحتياطي  

التفاصيل: `docs/PAYMOB_SETUP.md`

---

## هل يلزم شريك؟

**وحدك يكفي** للبيتا + الدفع اليدوي.  
لاحقاً عند الحاجة فقط: محاسب (سجل)، محامٍ (ساعة)، مساعد دعم، مطوّر عند أعطال حرجة.

---

## هذا الأسبوع (أول 7 أيام)

1. أكمل دورة شراء يدوية كاملة على جهازك  
2. اكتب مسودة خصوصية وشروط  
3. ادعُ 5 أشخاص موثوقين  
4. احجز استشارة محاسب قصيرة عن السجل — **بدون Paymob Live قبلها**

**مقياس نجاح المرحلة الأولى:** 10 مستخدمين أنهوا طلباً حقيقياً بدون ضياع فلوس أو بيانات.
