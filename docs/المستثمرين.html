1 — الملخص التنفيذي

يواجه طلاب الدراسات العليا تشتتاً بين مشرفين، مختبرات، معدات، كتابة، أصالة، ومجتمع — غالباً بلا ضمان مالي ولا مسار يربط الفكرة بالتنفيذ.

AcadeGate منصة ثنائية البوابة تجمع الرحلة الأكاديمية في تطبيق واحد: بوابة باحث للاستهلاك وبوابة مقدم خدمة للعمليات والعرض.

فكرة → مشرف → مختبر/عينات → متجر → كتابة → مجتمع → AI / أصالة / نشر → تمويل (عند التفعيل)
حالة المنتج الآن: جاهز لبيتا مغلقة بالتحويل اليدوي. مسار Paymob مبرمج وجاهز للتفعيل بعد التسجيل القانوني. لا توجد اشتراكات مستخدم مفعّلة في الكود بعد — لكنها جزء من نموذج التربح المقترح.

ماذا يطلب الاستثمار؟

  • تسجيل قانوني + تفعيل الدفع الإلكتروني
  • تعبئة محتوى حقيقي (مشرفون / مختبرات / موردون)
  • بيتا جامعية مغلقة ثم توسع
  • بناء طبقة الاشتراكات وربط دفع المختبرات
  • تسويق أكاديمي وفريق عمليات

4 — خريطة الخدمات: شرح دقيق + تصوّر التربح

4.1 المشرفون الأكاديميون تشغيلي

الوظيفة: دليل حسب الكليات، ملف، مقاييس نشر، مراسلة، طلب إشراف/تواصل، استيراد OpenAlex/CSV.

التربح: عمولة 10–15% على استشارات مدفوعة لاحقاً · اشتراك ملف مميز · ترخيص B2B لعرض مشرفي الجامعة · إعلانات تخصصية.

4.2 المطابقة الذكية تشغيلي

الوظيفة: مطابقة الملف الأكاديمي مع مشرفين/أفكار/مختبرات + تنبيهات.

التربح: Freemium (حد مجاني) · اشتراك Premium للمطابقة غير المحدودة · ضمن باقة «باحث Pro».

4.3 سوق الأفكار البحثية تشغيلي

الوظيفة: نشر أفكار، تصويت، مقترحات، مراجعة قبل الظهور.

التربح: رسوم نشر مميز · عمولة عند تحويل المقترح لتعاقد (كتابة/مختبر) · تحديات بحثية برعاية مؤسسات.

4.4 مسار البحث الذكي تشغيلي / تمييزي

الوظيفة: من موضوع البحث إلى حزمة: فكرة + مشرف + مختبر + متجر + كتابة (+ AI).

التربح: قمع تحويل — مجاني جزئياً للجذب · رسوم تقرير Premium · عمولة إحالة عند تحوّل عناصر الحزمة لطلبات مدفوعة.

4.5 المختبرات · تحليل العينات · حجز الأجهزة طلبات جاهزة / دفع لاحق

الوظيفة: دليل مختبرات، طلب تحليل بدورة حالات، حجز أجهزة، صندوق وارد للمسؤول، استيراد/مطالبة مختبر.

دقة الحالة: دورة الطلبات والحجوزات تعمل. لا يوجد checkout بطاقة على العينات/الحجز بعد.
التربح: عمولة 8–12% على التحليل المدفوع · عمولة حجز جلسة · اشتراك مختبر مميز · عقد ربط مختبر جامعي B2B.

4.6 المتجر الأكاديمي قناة إيراد أساسية

الوظيفة: 5 أقسام منتجات، طلب شراء، اختيار Paymob أو تحويل يدوي، Escrow (محجوز→مُفرَج)، مراسلة.

الآن: التحويل اليدوي يعمل. Paymob: كود جاهز ويُفعَّل بعد السجل القانوني والأسرار.
التربح: عمولة 5–12% لكل طلب · اشتراك مورد · ترويج منتج · رسوم إعداد كتالوج للموردين الكبار.
مثال: سلة 800 ج.م × 8% = 64 ج.م/طلب → 500 طلب/شهر ≈ 32 ألف ج.م عمولة قبل التكاليف.

4.7 خدمات الكتابة الأكاديمية قناة إيراد أساسية

الوظيفة: 8 تخصصات كتابة بشرية، حجز، قبول/رفض، دفع يدوي/Paymob، تسليم، تأكيد، مطابقة كاتب.

التربح: عمولة 10–20% · اشتراك خبير مميز · رسوم استعجال تُقسم · رسوم مطابقة كاتب ضمن Pro.

4.8 المجتمع وغرف البحث تشغيلي

الوظيفة: غرف تخصص + غرف بحث محمية بكلمة مرور (Cloud Functions) + مناقشات وإشعارات.

التربح: غرف مؤسسية مدفوعة · رعاية خفيفة · قيمة أساسية = احتفاظ وإحالة للخدمات المدفوعة.

4.9 المساعد الأكاديمي (AI) تشغيلي / تكلفة API

الوظيفة: وكلاء متخصصون عبر Gemini، مرفقات، حفظ محادثات.

التربح: Freemium · اشتراك باحث Pro (99–299 ج.م/شهر مقترح) · ترخيص جامعي · رصيد Pay-per-use.
التسعير يجب أن يغطي تكلفة Gemini + هامش مستهدف ≥ 50% بعد الاستقرار.

4.10 محاكي المناقشة (Viva) تشغيلي

الوظيفة: محاكاة لجنة، أسئلة مرتبطة بالمحتوى، صوت، جلسات، تصدير.

التربح: ضمن Pro · دفع لكل جلسة · حزمة ما قبل المناقشة (محاكاة + منهجية).

4.11 النزاهة والمنهجية والإحصاء تشغيلي

الوظيفة: فحص مراجع، أصالة (Copyleaks)، تقرير منهجية، معالج افتراضات إحصائية.

التربح: دفع لكل فحص أصالة (تكلفة مزوّد + هامش) · تقارير مدفوعة · ضمن باقة Pro بحدود استخدام.

4.12 النشر العلمي تشغيلي

الوظيفة: مسودات، مجلات، قواعد تنسيق، استخراج بالـ AI، تصدير DOCX.

التربح: رسوم تنسيق حسب مجلة · اشتراك ناشر · عمولات إحالة تحرير/مجلات لاحقاً.

4.13 صندوق تمويل البحث واجهة جاهزة / غير مفعّل حتى إعداد الشريك

الوظيفة: تمويل أفكار عند عتبة تصويت؛ إعداد إداري للشركاء والجوائز.

التربح: رسوم إدارة منحة · رعاية ظهور الشريك المموّل — نموذج شراكة مضبوط وليس crowdfunding عام مفتوح.

4.14 أخبار علمية · رسائل · إشعارات · رحلة الرسالة

الوظيفة: RSS حي، محادثات، إشعارات داخل التطبيق (مؤمّنة بعلاقة طرفين)، تتبع مراحل الرسالة.

دقة: FCM Push من السيرفر غير مكتمل بعد (التوكن يُحفظ).
التربح: بنية احتفاظ وتحويل — ترفع إتمام الطلبات المدفوعة؛ إعلانات أخبار ثانوية.

4.15 الإدارة والاستيراد ولوحة المساهمة

الوظيفة: مراجعة محتوى، استيراد مشرفين/مختبرات/متجر، عمليات مختبرات غير مربوطة.

التربح: تمكين العرض بسرعة → معاملات أكثر. يمكن بيع «خدمة إعداد محتوى» كمشروع للجامعات/الموردين.

9 — الخلاصة وطلب الاستثمار

AcadeGate اليوم منصة تشغيلية حقيقية — وليست مجرد نموذج واجهة. تجمع اكتشاف الموارد الأكاديمية مع مسارات تجارة قابلة للعمولة (متجر/كتابة)، وأدوات ذكاء قابلة للتحويل لاشتراكات عالية الهامش، ومسار واضح من بيتا يدوية إلى دفع إلكتروني مؤسسي وتوسع جامعي.

الطلب: شريك رأسمالي يموّل الانتقال من «منتج يعمل» إلى «سوق يعمل بأرقام» عبر الامتثال، المحتوى، والتفعيل التجاري.
